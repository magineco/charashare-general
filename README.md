# キャラシェア・ジェネラル (charashare general)

TRPG(テーブルトークRPG)のキャラクターシートを、利用者自身が任意のシステム向けに
テンプレートとして作成し、Googleアカウントでログインして**利用者自身のGoogle
Driveに保存・共有できる**Webツールです。「キャラシェア」というサービスの一部
(汎用エンジン部分)を公開しています。

公開版: https://magineco.com/charashare/general/

## 特徴

- ユーザー情報もキャラクターデータも運営のサーバー・DBには一切残さない設計。
  すべて利用者自身のGoogle Drive上に保存されます。
- ビルドツールなし・フレームワークなしの、単一HTMLファイル完結のバニラJS。
- 項目・計算式・参照・チェックボックス・画像欄・データリストなどを組み合わせて、
  任意のTRPGシステム向けのキャラクターシートを自分で作成できます。

## リポジトリの構成

```
privacy-policy.html     プライバシーポリシー
terms-of-service.html   利用規約
general/
  index.html            本体(テンプレート編集・キャラクター作成・閲覧)
  faq.html              よくある質問
  hero.jpg              トップ画面のヒーローバナー画像
  og-image.png          SNS共有カード(OGP)用の画像
```

`general/index.html`はプライバシーポリシー・利用規約への相対リンク
(`../privacy-policy.html`など)を持つため、ルート直下にこの2ファイルを
一緒に置いています。

## このリポジトリに含まれないもの

本番環境では、上記のクライアント側コードに加えて、以下の**非公開のサーバー
サイド処理**(Google Cloud Functions)を組み合わせて動かしています。これらは
セキュリティ上の理由からこのリポジトリには含めていません。

- **OAuth認可コード⇔アクセストークン交換プロキシ**:
  Google Identity Servicesの認可コードフロー(`initCodeClient`)を使っており、
  ブラウザはGoogleから認可コードのみを受け取ります。アクセストークンへの交換には
  `client_secret`が必要なため、これをサーバー側のプロキシに代行させています。
- **共有リンクの復号プロキシ(概念のみ)**:
  キャラクターやテンプレートをリンクで共有する際、実際のGoogle DriveファイルIDを
  そのままURLに載せると、リンクを受け取った人がDrive本体を直接開いて
  オーナーの実名を見られてしまいます。これを防ぐため、公開URLには実IDの代わりに
  **暗号化されたトークン**を載せ、「トークンを渡すとDrive上の該当ファイルの
  JSONを返す」という一種の復号プロキシを経由する設計にしています。
  この仕組み自体(サーバーの実装・暗号鍵の管理)は非公開です。ここで説明しているのは
  「トークン→JSON」という概念のみで、実際のコードや鍵は含まれていません。

そのため、このリポジトリのコードだけをそのまま動かした場合:

- ✅ キャラクターシートの作成・編集、テンプレート作成、ローカルJSONファイルの
  読み込み・ダウンロードは、そのまま動作します。
- ❌ Googleログイン、Google Driveへの保存、共有リンクの発行・閲覧は動作しません
  (上記の非公開バックエンドが必要です)。これらの機能を再現したい場合は、
  同等のプロキシをご自身で用意してください。

## ローカルでの動作確認

ビルド不要です。`general/index.html` をブラウザで直接開くか、任意の
静的ファイルサーバーで配信してください。

```bash
npx serve .
```
